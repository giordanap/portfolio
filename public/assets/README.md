# Portfolio Media Assets

This folder contains static media used by the portfolio.

Recommended formats:

- WebP or AVIF for images
- SVG for icons and technical illustrations
- WebM or MP4 for short previews
- PDF for the downloadable CV

Do not commit very large media files. Optimize assets before adding them.

Suggested optimization rules:

- Project covers: 1600x1000 or smaller
- Profile portrait: 800x800 or smaller
- Backgrounds: compressed WebP, AVIF or lightweight SVG
- Short previews: WebM preferred over GIF

GitHub Pages paths should be referenced through the project base path helper when used from components.
